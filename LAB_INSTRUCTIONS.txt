--------------------------------------------------------------------------------
PART 1: LINUX LAB ENVIRONMENT SETUP & LIBRARIES
--------------------------------------------------------------------------------
Open your Linux terminal (Ctrl + Alt + T) in the folder containing your programs:

1. (Optional but recommended) Create and activate a virtual environment:
     python3 -m venv ml_env
     source ml_env/bin/activate

2. Install the required Python libraries:
     pip install numpy pandas scikit-learn matplotlib

   * If pip is not installed on the Linux system:
     sudo apt update && sudo apt install -y python3-pip python3-tk

   * If matplotlib gives a GUI display error (Tkinter missing on Linux):
     sudo apt install -y python3-tk

--------------------------------------------------------------------------------
PART 2: EXACT LINE TO REPLACE IN EACH PROGRAM
--------------------------------------------------------------------------------
In each program, look around lines 14–16. You will see:
   dataset_path = "..."
Simply replace the quoted text with the actual path to your downloaded CSV file.

On Linux, you can use:
  - Relative path (if CSV is in the same folder):  dataset_path = "iris.csv"
  - Absolute path:                               dataset_path = "/home/student/Downloads/iris.csv"
  - URL (if allowed to fetch online):            dataset_path = "https://raw.githubusercontent.com/.../iris.csv"

--------------------------------------------------------------------------------
PART 3: STEP-BY-STEP LAB EXECUTION IN LINUX
--------------------------------------------------------------------------------
1. Download or copy your CSV file onto the Linux machine.
   (For example, save it into the same folder as the Python scripts).

2. Open the python file in any editor (VS Code, gedit, or nano):
     gedit linear_svm_iris.py
   or
     nano linear_svm_iris.py

3. Replace line 15 with your file's path:
     dataset_path = "iris.csv"

4. Save the file and run it in terminal:
     python3 linear_svm_iris.py

5. The program will:
   a) Print the dataset confirmation and shape.
   b) Print the first 5 rows and 6 columns (as required for lab viva/evaluation):
        print(df.iloc[:5, :6])
        print(df.head())
   c) Preprocess features, split train/test sets, and train the model.
   d) Output performance metrics (Accuracy, Classification Report, Confusion Matrix).
   e) Pop up the interactive Matplotlib plot window for the examiner.
   f) Close the plot window to return to the shell.

--------------------------------------------------------------------------------
PART 4: TROUBLESHOOTING IN LINUX LABS
--------------------------------------------------------------------------------
Q1: "ModuleNotFoundError: No module named 'pandas'" (or sklearn, matplotlib, numpy)
A1: Run: pip3 install numpy pandas scikit-learn matplotlib

Q2: "FileNotFoundError: [Errno 2] No such file or directory: '...'"
A2: Check your path. In Linux, paths are case-sensitive. If your file is in Downloads,
    use: dataset_path = "/home/<your_username>/Downloads/your_dataset.csv"
    Or place the CSV directly in the same folder as the script and use:
    dataset_path = "your_dataset.csv"

Q3: Plot window doesn't appear or says "$DISPLAY not set" (Headless / SSH session)
A3: If running remotely or without a GUI, add this at the top of the script to save
    plots directly as PNG files:
      import matplotlib
      matplotlib.use('Agg')
    And replace plt.show() with:
      plt.savefig('output_plot.png')
